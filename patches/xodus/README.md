# xodus patches

`0001`–`0007` are BedrockOnLinux's fixes to xodus (licensing and streaming
error handling, sign-in flow), copied unchanged from
[Wyze3306/BedrockOnLinux](https://github.com/Wyze3306/BedrockOnLinux) `third_party/xodus/patches`
(BedrockOnLinux is MIT; the patches modify GPL-3.0 xodus and are GPL-3.0 as part of it).
They apply in order to the commit pinned in `third_party/xodus.env`.
